# Agent Notes Instructions

These files preserve durable product and engineering decisions. Follow the root `AGENTS.md` and the format in `README.md`.

- Search existing notes before adding one; update the note that already owns the decision.
- Put unshipped decisions under `proposed/` and shipped decisions under `implemented/`.
- Use `architecture`, `feature`, `bug-fix`, `process`, or `testing` as the category.
- Move a proposed note to `implemented` when it ships and rewrite planned language as the delivered decision.
- Never put secrets, access tokens, production personal data, or copied chat reasoning in a note.
- Prefer one concise note per durable decision. Small local implementation details do not require a note.
